# RTL / Persian Integration

1. Set the document language and direction for the product.
2. Configure a verified Persian-capable font stack.
3. Prefer logical CSS properties such as inline-start/inline-end.
4. Audit navigation, forms, dialogs, tables, pagination, breadcrumbs, charts, and icons.
5. Add localized date/number formatting only where required.
6. Test mixed Persian/English labels and technical terms.
7. Test responsive layouts at narrow mobile widths.
8. Verify keyboard and screen-reader behavior.
