# RTL / Persian Verification

Check at minimum:

- Persian-only heading and paragraph
- line beginning with a Latin technical term followed by Persian
- Persian text containing an inline URL
- numbers, dates, parentheses, slashes, and punctuation
- form labels, inputs, validation messages
- data table with Persian and English columns
- breadcrumb and pagination
- mobile navigation
- keyboard tab order
- copy/paste behavior for mixed-direction content
