# starter-web

## Purpose
Default starting point for general client websites and interactive web apps.

## Core stack
- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui

## Include
- responsive shell/layout
- metadata/SEO baseline
- accessible navigation
- loading/error/not-found patterns
- basic form pattern
- test setup
- GitHub Actions baseline
- AGENTS.md
- environment example

## Exclude by default
- auth
- database
- payments
- CMS
- AI
- storage
- analytics provider

Add those through feature packs only when required.

## Good fit
- corporate/product site
- web tool
- client portal without specialized domain starter
- booking frontend
- internal utility

## Verification
- clean install/build
- responsive smoke test
- accessibility baseline
- no optional provider required to boot
