# starter-ai

## Purpose
AI-first client products such as chat, assistants, document Q&A, and AI utilities.

## Core stack
- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- Vercel AI SDK

## Include
- streaming chat pattern
- message history interface
- model/tool boundary abstraction
- loading/error/cancel states
- prompt/input safety boundaries
- testable server-side AI route pattern

## Common packs
- auth
- database
- storage
- rag
- pdf
- monitoring

## Exclude by default
- vector database
- RAG
- file upload
- billing
- provider-specific model lock-in beyond the minimal adapter
