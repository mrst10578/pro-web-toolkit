# starter-cms

## Purpose
Sites where the client/editor must manage content without code changes.

## Core stack
- Next.js
- TypeScript
- Tailwind CSS
- Payload

## Include
- CMS/app integration pattern
- content collection examples
- preview/draft conventions
- media handling conventions
- SEO field conventions
- editor/admin guidance

## Common packs
- search
- email/forms
- analytics
- rtl-persian

## Exclude by default
- commerce
- membership
- AI
- custom workflow automation
