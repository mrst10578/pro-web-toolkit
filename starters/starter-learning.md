# starter-learning

## Purpose
Education products: LMS, quiz, exam, question bank, practice, and progress tracking.

## Core stack
- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui

## Domain model baseline
- user/learner
- subject/course
- chapter/topic
- question/item
- answer/choice
- attempt
- assessment/exam
- result
- progress
- tags/difficulty

## Include
- domain boundaries and example types
- question rendering contract
- attempt/result state model
- admin/content workflow placeholders
- accessibility for question navigation
- test fixtures for deterministic scoring

## Common packs
- auth
- database
- storage
- analytics
- pdf
- rtl-persian

## Exclude by default
- payment
- video platform
- live classes
- certificates
- AI tutoring
unless explicitly required.
