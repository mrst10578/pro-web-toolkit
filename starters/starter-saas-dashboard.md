# starter-saas-dashboard

## Purpose
Logged-in SaaS products, portals, admin panels, and operational dashboards.

## Core stack
- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui

## Include
- application shell/sidebar
- dashboard layout
- data-table pattern
- settings/profile pattern
- empty/loading/error states
- role-aware UI hooks without hardcoding an auth provider
- test and CI baseline

## Feature packs commonly added
- auth
- database
- payments
- email
- analytics
- monitoring

## Exclude by default
- Stripe/Supabase/provider SDKs until selected by project brief
