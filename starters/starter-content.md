# starter-content

## Purpose
Content-heavy websites where reading, SEO, and fast page delivery are primary.

## Core stack
- Astro
- TypeScript
- Tailwind CSS
- Markdown/MDX or Astro Content Collections

## Include
- article/content layouts
- SEO metadata
- sitemap/robots baseline
- RSS-ready structure
- pagination/category/tag patterns
- image optimization conventions
- search-ready content model

## Exclude by default
- user auth
- transactional database
- payments
- heavy client-side state

## Good fit
- magazine
- blog
- documentation-like public content
- university/major/province directories
- editorial/SEO sites
