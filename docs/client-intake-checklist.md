# Client Intake Checklist

Use this before selecting a starter.

## Product

- What is the site/app supposed to let the user accomplish?
- Who are the user types?
- Is the product mainly content, tool, dashboard, commerce, education, or AI?
- What is explicitly out of scope?

## Features

- Login/accounts?
- Admin panel?
- CMS/editor?
- Payments/subscriptions?
- Search?
- File/image/PDF uploads?
- Email notifications?
- Realtime/chat?
- AI/RAG?
- Scraping/import from external sources?
- Reports/PDF exports?

## Data

- What data must persist?
- Who owns each type of data?
- Is any data sensitive?
- Does existing data need migration/import?
- What backup/recovery expectation exists?

## Delivery

- SEO importance?
- Mobile/PWA requirement?
- Languages/RTL?
- Hosting preference?
- Domain/DNS ownership?
- Analytics/monitoring needed?
- Deadline and launch-critical paths?

## Output

After intake, record only:
1. chosen starter
2. required feature packs
3. exceptional architecture decisions
4. acceptance checks
